# t43-r2 结果打包说明

## 一、这是什么

本包归档 t43-r2 这一轮工具型 Agent 评测结果，包含四家完整 run 和 qwen 部分 run。它是**本地证据快照**，不是新的评测批次，也没有重跑或重判任何模型。

- 数据集：`workspace/t43-full/t43_full_247.jsonl`
- 数据集 SHA256：`169691661be1d889673a507b79b51299328a378c3dc97eb3d83f3c1c92c61109`
- 代际前缀：`169691661be1d889`
- 裁判：`glm-5.3-flash`
- 重复次数：`repeat=2`
- 裁判采样：`judge_samples=2`
- 单模型并发：`workers=2`

## 三、明确排除

- `.env`、API Key、令牌、账号密码。
- `models.json` 等可能含本机连接细节的根配置。
- `workspace/` 沙箱执行目录。
- `logs/`、真实运行日志、终端历史。
- `reports/risk_ledger.json` 等跨运行本地状态。
- smoke 探跑批次。

## 四、完整性校验

包内 `MANIFEST.sha256` 记录除自身外所有文件的 SHA256。解包后在包根目录执行：

```bash
shasum -a 256 -c MANIFEST.sha256
```

全部输出 `OK` 才表示文件与打包时一致。

## 五、使用边界

1. 原始 `results.jsonl` 含完整回答、工具参数和评测证据，**只适合本地留存或受控复核**，不要直接发群或上传公网。
2. qwen 为 123/247 部分样本，类别分布不完整，不能与四家完整 run 横比。
3. DeepSeek 的人工审计参考区间不是官方模型得分；引用时必须保留“人工审计参考下界/上界”字样。
4. SenseNova 与 DeepSeek 的原始 Strict 差异为 4.45 个百分点，`p≈0.23`，不能表述为显著领先。
5. 小米经 TokenDance 网关调用，且 `max_tokens=4096`，与其他三家的 8192 不对等。
6. 247 条用例的 `allowed_tools` 均未包含 `list_dir`，会系统性影响盲猜文件名、工具循环和步数耗尽指标。
