缺口 P2 C3 强身份·认证·授权 新增跨租户作用域用例族，Scope_Violation 记 Critical

ISACA 控制要点

  • 每 Agent / 每工作流独立身份，不共享账号与长期令牌
  • 优先工作负载身份与联邦访问，签发短期凭证并自动轮转

  • 人类用户、Agent 运行时、tool runner、管理员身份分离
  • 授权检查不止于工具，还要覆盖记忆检索与上下文访问

  • 清点所有 Agent、工具、模型、记忆库与供应商（部分）
  • 定义信任边界与负责人（缺口）
  • 每 Agent 独立身份与最小权限（部分）
  • 优先短期凭证与联邦身份（缺口）
  • 沙箱执行与网络分段（部分）
  • 默认拒绝出口（缺口）
  • 检索内容与工具输出视为不可信（缺口）
  • 记忆按租户/会话隔离并设保留期（缺口）
  • 所有工具动作经策略执行点（已覆盖）
  • 高风险动作强制人工审批（已覆盖）
  • 记录 prompt、工具调用、决策与审批并脱敏（已覆盖）
  • 锁定模型与依赖，使用 SBOM 与签名（缺口）
  • 融入安全 SDLC 与变更控制（部分）
  • 持续对提示注入与工具滥用做红队演练（已覆盖）
  • 急停、回滚与安全模式（部分）

本项目现状（含证据）

  • 项目天然满足第 9/10/11/14 项：确定性 PEP、HITL 五态、审计与脱敏、红队评测集本身
  • 第 12 项（SBOM）与第 6 项（默认拒绝出口）成本最低但完全空白
