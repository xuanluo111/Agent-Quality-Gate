## 六、诚实边界（不能越过的一句话）

- 项目是**评测 Harness + 发布门禁**，不是 Agent 运行时、也不是生产安全平台：不能声称做到 OS 级沙箱、真实网络分段、真实密钥托管、企业 IAM——这些是 SUT（被测系统）的责任，Harness 只能**验证或模拟**。
- **AWS 是类比口径**：S1/S2/S3 是 Harness 内数据路由策略，`README.md:59` 已明确「没有实际部署 AWS 或端侧服务」。
- 四框架对齐矩阵中，只有第二/三节**带代码锚点或 ledger 证据**的条目才是「实际用到」；第四节是「做过的事如何解读」，第五节明确是「还没做」。
