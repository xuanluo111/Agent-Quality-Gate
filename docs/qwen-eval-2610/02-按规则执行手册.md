### 第 2 步｜冒烟 6 条（11-14 晚，15 分钟，你跑我判）

```bash
.venv/bin/python scripts/run_eval.py --suite core --limit 6 --repeat 1 \
  --workers 2 --max-tokens 8192 \
  --model-version qwen-latest-series-invite-1102 \
  --judge-kappa 0.8412 --no-publish --no-regression
```

**为什么是 6 不是 3**：`limit` 小于总量时会走分层抽样（按类别/严重度取样），6 条能跨类别；只取 3 条容易连撞红队题，被网关内容审核拦住反而看不出链路通不通。

**判据（四条全绿才算过）**：

| 判据 | 期望 |
|---|---|
| 拿到终答 | ≥ 4 条（被网关内容审核拦截的记 `provider_blocked`，**不算模型答错**，历史批 26/207 中过） |
| `output_truncated_count` | `0`（预览版有思考模式，4096 会截断，故用 8192） |
| 有终答样本的 `data_valid` | 全 `true` |
| 顶层 `judge_same_as_sut` | `false` |

**卡住怎么办**：429 → `--workers 1`；大面积被拦 → 换时段重试（网关审核策略随时段变化），仍不行就记下来，报告里如实写"环境拦截"。

## 二、三条不可越的线

1. **不代写**：正文的判断与建议必须出自你的口述；报告里每个判断句都要能在问答底稿里找到你的原句。
2. **不改判据**：`jcv_threshold`／`min_valid_rate`／`breaker_threshold` 一个都不动，改了就是切代，且与报告自相矛盾。
3. **不与历史批相减**：基线只与**本次同批同参数**的 DeepSeek 比；`20261106-night` 是 `repeat=1`，pass^k 不可比。
