> **对象**：《自进化智能体的评估判据：三条可证伪的要求》三页草案，页眉日期 2026-11-19，用于 RSI 评测研究组（筹）第一次技术研讨会（北京）。

> **性质**：只更正数字与口径，不改判据主张。本文不含代码改动。
> **纪律**：仓库内引用会场材料数字时，一律带「2026-11-19 报告材料，未独立核验」；本文所列四处**不得**再按三页纸原值引用。

## 一、四处更正

### ① §2.3「47 条 harness 异常」——这个数在对应批次里不存在

| 项 | 内容 |
|---|---|
| 三页纸原文 | 「某批 207 条中有 26 条被云厂商内容审核拦截、**47 条 harness 异常**，有效样本率 70.79%」 |
| 对应批次 | `reports/runs/20261106-night-diandian-dots3-note-pre/`（`git_sha=ee5997e`，裁判 `glm-4-flash`，`max_tokens=4096`，`repeat=1`） |

| gate 原文 | 「失败来源：网关内容审核拦截 **26** 条；Harness/网关异常 **52** 条」 |
| 正确口径 | **26 + 52 = 78 = `untrusted_samples`**（`harness_error_count` 装的是全部不可信样本，不是其中一类，字段名易误读） |
| 47 的可能出处 | `reports/runs/20261118-131428-zhipu-glm-4.5-flash/observability.json` → `ledger.status_counts.regressed = 47`，即**另一批的台账回归数**，与 harness 异常无关 |

> 附更正说明：11-19 晚排期时曾把 47 解释为「attempt 级事件数」。**该解释无据**——这场 `repeat=1`，不存在 attempt 级与用例级之分。已按实况改写。

### ② §2.3 的 70.79% 缺分母，且与本节自己的主张相左

三页纸 §2.3 的立论是「通过率必须随附分母」，但它自己写的 `70.79%` 没有交代分母是谁。

- 实况：`valid_cases = 126`，`measurable_cases = 178`，`total = 207` → **126 / 178 = 70.79%**
- 分母是 **178（可测样本）**，不是 207；207 里那 29 条根本没进入可测集
- 若按 207 作分母，同一批会读成 60.87%，与页面数字对不上

**引用时必须写成**：`有效样本率 70.79%（126/178 可测样本，总 207 条）`。
